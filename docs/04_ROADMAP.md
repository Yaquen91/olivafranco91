# Roadmap del Proyecto

**Versión:** 1.0
**Estado:** Activo

---

# Objetivo

Este documento define la evolución planificada de Franco Brand.

No pretende contener todas las ideas futuras.

Su objetivo es mantener el foco del proyecto y priorizar únicamente aquello que aporte valor a la marca.

Cada nueva funcionalidad debe responder a una necesidad real y estar alineada con la misión definida en `01_BRAND.md`.

# Prioridad actual

Toda decisión debe contribuir a publicar una primera versión profesional de la web.

No se incorporarán funcionalidades que retrasen ese objetivo.

La prioridad es construir una base sólida sobre la cual evolucionar.

---

# Cómo se priorizan las tareas

Antes de comenzar una nueva implementación, responder:

* ¿Es necesaria para publicar la primera versión?
* ¿Aumenta la confianza del visitante?
* ¿Está alineada con la misión de la marca?
* ¿Puede esperar para una fase posterior?

Si una funcionalidad no supera estas preguntas, debe posponerse.

---

# Definición de "Versión 1.0"

La primera versión de Franco Brand estará lista cuando:

* La Home represente correctamente la marca.
* El contenido sea real.
* Los proyectos principales estén publicados.
* La navegación sea clara.
* La experiencia responsive esté revisada.
* La web pueda compartirse públicamente con confianza.

No es necesario que todas las funcionalidades futuras estén implementadas.

La versión 1.0 representa el inicio de la marca, no su estado final.

---

# Filosofía de evolución

Franco Brand es un proyecto a largo plazo.

La web evolucionará junto con la carrera profesional.

No se busca construir una plataforma completa desde el primer día.

Se busca construir una base sólida que permita crecer de forma ordenada, incorporando nuevas funcionalidades únicamente cuando aporten valor real.

La prioridad siempre será la calidad antes que la cantidad.
