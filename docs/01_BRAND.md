# ¿Qué es Franco Brand?

Franco Brand no es simplemente un portfolio.

Tampoco es una academia, una página para vender cursos o un sitio donde mostrar proyectos.

Franco Brand es la plataforma desde donde voy a construir mi marca profesional alrededor de Unreal Engine.

Este proyecto nace con un objetivo muy claro: compartir conocimiento útil, mostrar experiencia real y generar la confianza necesaria para que personas, estudios y empresas quieran aprender o trabajar conmigo.

La web es solamente el punto de encuentro.

La marca es mucho más grande que el sitio.

---

# Misión

Ayudar a desarrolladores y equipos a construir mejores proyectos con Unreal Engine mediante herramientas, flujos de trabajo eficientes y formación técnica basada en experiencia real.

No quiero enseñar únicamente cómo funciona Unreal Engine.

Quiero enseñar cómo desarrollar proyectos de una forma más profesional, organizada y mantenible.

---

# Visión

Construir una marca profesional reconocida por compartir soluciones reales para el desarrollo con Unreal Engine.

A largo plazo quiero que Franco Brand sea un lugar donde cualquier desarrollador pueda encontrar contenido útil sobre:

* Editor Tools
* Utility Widgets
* Blueprint Architecture
* Flujos de trabajo para desarrolladores
* Automatización de tareas
* Optimización de pipelines
* Formación técnica
* Mentorías
* Desarrollo de videojuegos

Mi objetivo es que, cuando alguien tenga un problema relacionado con Unreal Engine, piense:

> "Veamos si Franco ya explicó cómo resolverlo."

---

# ¿Qué problema busca resolver esta marca?

En muchos proyectos de Unreal Engine se pierde tiempo realizando tareas repetitivas, manteniendo Blueprints difíciles de escalar o utilizando procesos poco eficientes.

Quiero ayudar a mejorar esa situación.

Siempre que sea posible, el contenido deberá responder preguntas como:

* ¿Cómo podemos automatizar esta tarea?
* ¿Cómo hacemos este Blueprint más mantenible?
* ¿Cómo puede un diseñador trabajar más rápido?
* ¿Cómo mejoramos el flujo de trabajo del equipo?
* ¿Cómo reducimos errores durante el desarrollo?
* ¿Cómo organizamos un proyecto para que pueda crecer?

El objetivo nunca será enseñar una herramienta por sí sola.

El objetivo será mostrar cómo esa herramienta mejora el desarrollo de un proyecto.

---

# Posicionamiento

No quiero que la marca sea conocida simplemente como:

> "Un instructor de Unreal Engine."

Quiero construir un perfil mucho más específico.

La marca se posiciona en la intersección de tres pilares:

## Construcción de herramientas

Desarrollo de herramientas que simplifican el trabajo dentro de Unreal Engine.

## Mejora de flujos de trabajo

Búsqueda constante de procesos que permitan desarrollar videojuegos de forma más eficiente.

## Formación técnica

Compartir conocimiento práctico obtenido durante el desarrollo de proyectos reales.

Estos tres pilares siempre deben aparecer juntos.

Si uno desaparece, la identidad de la marca pierde fuerza.

# Filosofía

Todo el contenido de Franco Brand debe nacer de una experiencia real.

No quiero crear ejemplos artificiales únicamente para enseñar una herramienta.

Prefiero explicar cómo resolví un problema durante el desarrollo de un proyecto y utilizar esa experiencia para enseñar conceptos que otros puedan aplicar.

Cada proyecto debe responder estas preguntas:

* ¿Cuál era el problema?
* ¿Por qué era un problema?
* ¿Cómo lo resolví?
* ¿Qué aprendí?
* ¿Cómo puede aplicarlo otra persona?

Enseñar desde la experiencia genera mucho más valor que enseñar desde la teoría.

# Valores

## Profesionalismo

La confianza se construye con trabajo consistente.

## Honestidad

Nunca exagerar experiencia ni inventar resultados.

## Aprendizaje continuo

Siempre habrá algo nuevo para aprender y compartir.

## Calidad

Es preferible publicar menos contenido, pero que cada publicación aporte valor.

## Generosidad

Compartir conocimiento útil sin complicar innecesariamente los conceptos.

## Curiosidad

Mantener la mentalidad de alguien que disfruta resolver problemas.

# Identidad visual

La dirección visual de Franco Brand se define como **Technical Editorial / Unreal Developer**.

La web, el canal de YouTube, las miniaturas y los proyectos deben sentirse parte de una misma identidad profesional.

## Jerarquía cromática

* Negro y carbón para fondos y estructura.
* Blanco y gris claro para contenido y titulares.
* Naranja cálido para acciones y conceptos protagonistas.
* Cyan para Unreal Engine, información técnica y estados interactivos.

El color siempre debe tener una función. La interfaz debe evitar el exceso de glow, la estética cyberpunk, el gaming genérico y la decoración tecnológica sin propósito.

## Recursos visuales

* Titulares fuertes y editoriales.
* Paneles técnicos oscuros y bordes finos.
* Numeración editorial y etiquetas mono.
* Grillas y líneas de fondo extremadamente sutiles.
* Cortes diagonales discretos.
* Microinteracciones cortas y precisas.

La marca profesional debe utilizar, cuando corresponda, las formas exactas **FRANCO OLIVA**, **UNREAL AUTHORIZED INSTRUCTOR** y **APRENDER · CREAR · ENSEÑAR**.

---

# Tono de comunicación

La comunicación debe sentirse como una conversación entre desarrolladores.

Debe ser técnica cuando sea necesario, pero siempre clara.

Se debe priorizar explicar el "por qué" antes que simplemente mostrar el "cómo".

No utilizar títulos exagerados ni lenguaje orientado al clickbait.

La autoridad debe construirse mediante el contenido, no mediante el marketing.

---

# Qué hace diferente a Franco Brand

La mayoría del contenido sobre Unreal Engine se centra en enseñar funcionalidades del motor.

Franco Brand busca enseñar cómo trabajar mejor con Unreal Engine.

Eso implica hablar de:

* herramientas;
* procesos;
* organización;
* arquitectura;
* automatización;
* productividad;
* mantenimiento;
* colaboración entre equipos.

Gameplay seguirá formando parte del contenido, pero no será el principal elemento diferenciador.

# Principios para tomar decisiones

Antes de agregar cualquier nueva funcionalidad, sección o contenido, responder siempre estas preguntas:

* ¿Aumenta la confianza del visitante?
* ¿Aporta valor real?
* ¿Está alineado con la misión de la marca?
* ¿Ayuda a construir mejores proyectos con Unreal Engine?
* ¿Refuerza alguno de los tres pilares principales?

Si la respuesta es "no", probablemente esa idea no pertenezca a Franco Brand.

---

# Cómo mediremos el éxito

El objetivo de la web no es únicamente conseguir alumnos.

El objetivo es generar confianza.

Si una persona visita la web y termina pensando:

> "Quiero trabajar con Franco."

o

> "Quiero aprender con Franco."

entonces la marca está cumpliendo su propósito.

Los cursos, las mentorías, las colaboraciones y las oportunidades laborales serán una consecuencia de esa confianza, no el objetivo principal del sitio.
